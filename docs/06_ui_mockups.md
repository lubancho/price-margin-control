# 06. Макеты интерфейса

Целевой экран — ноутбук 1366×768 и 1440×900. Сетка Streamlit: боковая панель 260 px + рабочая область, разбитая на 12 условных колонок (`st.columns`). Высоты — ориентировочные, в пикселях. Цифры в макетах — заглушки.

## Общий стиль

| Элемент | Решение |
|---|---|
| Палитра | Нейтральная: фон `#F7F8FA`, текст `#1F2933`, акцент сине-серый `#3E5C76`; статусы: критично `#B3261E`, предупреждение `#B26A00`, норма `#2E7D32`, информация `#5B6B7A` |
| Шрифт | Системный (Inter / Segoe UI), таблицы — табличные цифры |
| Числа | Деньги `12 345 ₽`, проценты `43,6%`, изменение со знаком `+8,4%` |
| Статус | Цветная метка + текст (не только цвет — для доступности) |
| Подвал каждого экрана | «Демонстрационные синтетические данные. Не являются показателями реальной компании.» |
| Пустое состояние | Текст «Нет данных за выбранный период» вместо пустой таблицы |

## Макет 3. Таблица с фильтрами «Анализ цен» (приоритет 1)

```
┌──────────────┬─────────────────────────────────────────────────────────────────────┐
│ БОКОВАЯ      │ Анализ цен · расчёт от 31.03 · правила v3 · запуск 7f3a…  [Рассчитать]│
│              ├─────────────────────────────────────────────────────────────────────┤
│              │ [Период ▾][Точка ▾][Категория ▾][Товар 🔍][Тип отклонения ▾][Статус ▾]│
│              │ Сводка: предложено 412 · конфликт 27 · блок 15 · промо 106    h=40  │
│              ├─────────────────────────────────────────────────────────────────────┤
│              │☐│Точка    │Товар         │Катег.│Себест.│Цена│Маржа│Рек.│±₽ │±%  │Причина       │Статус   │
│              │☐│Омск-Л1  │Филадельфия   │Роллы │152,40 │249 │38,8%│270 │+21│+8,4│Рост себест.; │●Предлож.│
│              │ │         │              │      │       │    │     │    │   │    │лимит 10%     │         │
│              │☐│Омск-Ц2  │Сет «Север»   │Наборы│610,00 │799 │23,7%│ —  │ — │ —  │Конфликт:     │●Конфликт│
│              │ │         │              │      │       │    │     │    │   │    │лимит vs мин. │         │
│              │  … st.dataframe, h=440, сортировка по клику, 50 строк на страницу       │
│              ├─────────────────────────────────────────────────────────────────────┤
│              │ Выбрано: 2   [Согласовать] [Отклонить]  ← только роль «Руководитель»   │
│              │ [Открыть карточку выбранного]                                 h=48  │
└──────────────┴─────────────────────────────────────────────────────────────────────┘
```

Порядок колонок: идентификация (точка, товар, категория) → факт (себестоимость, цена, маржа) → предложение (рекомендация, изменение) → объяснение (причина, статус). Сортировка по умолчанию: критичность статуса, затем |изменение %| по убыванию.

«Тип отклонения»: ниже себестоимости / ниже мин. маржи / ниже целевой / отклонение от медианы сети / ошибка данных / без отклонений.
